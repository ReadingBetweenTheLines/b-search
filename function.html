💡 Petunjuk Simbol Operasi yang Digunakan: Bisa pakai * atau x untuk kali
Tambah +
Kurang -
Kali * atau x
Bagi /
Gabung Teks kataA + kataB (otomatis berspasi)
📚 Pola Penulisan Fungsi (Bisa Dipakai Berulang Kali):
Pisahkan parameter dengan tanda koma ( , )
Contoh: Fungsi Perhitungan Angka
hitungBalok (p, l, t):
   hasil = p * l * t
   kembalikan hasil

// Panggil fungsi di bawahnya:
hitungBalok(10, 5, 2) → 100
Contoh: Fungsi Penggabungan Teks
salamSiswa (sapaan, nama):
   hasil = sapaan + nama
   kembalikan hasil

// Otomatis tersambung dengan spasi:
salamSiswa("Halo", "Rian") → Halo Rian
